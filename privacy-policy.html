Privacy Policy

Kami menjelaskan data apa yang diproses, untuk tujuan apa, dan pilihan yang dimiliki pengguna.

1. Cakupan

Privacy Policy ini berlaku untuk ekstensi browser, situs web, autentikasi akun, dukungan pelanggan, dan proses pembayaran Auto Entry Assistant.

Auto Entry Assistant merupakan produk pihak ketiga. Produk ini bukan aplikasi resmi, tidak berafiliasi, dan tidak disponsori oleh pemilik portal target atau instansi pemerintah.

2. Data yang diproses

Kami memproses data berikut sejauh diperlukan untuk menyediakan layanan:

  • Email untuk pendaftaran, login, OTP, pemulihan password, dan komunikasi layanan.
  • Status akun, masa aktif, akses fitur, versi aplikasi, identitas sesi, dan identitas perangkat aplikasi.
  • Data pembayaran berupa order ID, paket, nominal, status, referensi pembayaran, dan waktu transaksi.
  • Preferensi ekstensi, input terakhir, progres, serta log sukses atau gagal yang disimpan lokal.
  • Konten formulir atau halaman portal target yang diperlukan untuk menjalankan fitur yang dipilih pengguna.

3. Data otomasi diproses lokal

Input pekerjaan dan hasil otomasi diproses pada browser pengguna. Contohnya mencakup NIB/NIBEL, nomor hak, Persil ID, data SU/Hak, data formulir, dan result proses.

Tidak dikirim ke server kami

Data pekerjaan tersebut tidak disimpan ke Supabase oleh fitur saat ini. Data dapat tersimpan pada Chrome Storage di perangkat pengguna agar pekerjaan dapat dilanjutkan dan result dapat ditinjau.

Kami tidak meminta atau menyimpan password portal target, tidak menjual data pengguna, dan tidak menggunakan data pengguna untuk iklan tertarget.

4. Layanan pendukung

Supabase

Autentikasi, database akun, sesi, akses fitur, konfigurasi workflow, dan status pembayaran.

SumoPod

Pembuatan pembayaran QRIS dan notifikasi status transaksi perpanjangan akun.

Brevo / SMTP

Pengiriman OTP, pemulihan akun, dan email transaksional.

Chrome Storage

Penyimpanan preferensi, input, progres, token sesi aplikasi, dan result pada perangkat pengguna.

Data hanya dibagikan kepada penyedia tersebut sejauh diperlukan untuk menjalankan fungsi layanan, keamanan, dukungan, atau memenuhi kewajiban hukum.

5. Retensi dan keamanan

Data akun dan pembayaran disimpan selama akun digunakan serta selama diperlukan untuk dukungan, audit transaksi, penyelesaian sengketa, pencegahan penyalahgunaan, dan kewajiban hukum.

Komunikasi antara ekstensi dan layanan kami menggunakan HTTPS. Akses database dibatasi menggunakan autentikasi dan kebijakan akses. Tidak ada metode penyimpanan atau transmisi yang dapat dijamin sepenuhnya bebas risiko.

Data lokal dapat dihapus dengan menghapus data ekstensi atau mencopot ekstensi dari browser. Tindakan tersebut tidak otomatis menghapus data akun dan transaksi pada server.

6. Hak pengguna

Pengguna dapat meminta informasi, koreksi data akun, bantuan akses, atau penghapusan akun. Permintaan dapat memerlukan verifikasi identitas dan dapat dibatasi apabila penyimpanan masih diperlukan berdasarkan kewajiban hukum atau penyelesaian transaksi.

Perubahan material pada praktik pemrosesan data akan disampaikan melalui pembaruan kebijakan atau pemberitahuan di aplikasi sebelum praktik baru diterapkan jika diwajibkan.
